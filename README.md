# Pallavi & Deepak — Wedding Invitation

A single-page, GitHub Pages-ready wedding invitation inspired by the reference invitation site.

## Files
- `index.html` — invitation content
- `style.css` — design and responsive layout
- `script.js` — scroll reveal animation

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload these three files.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will provide the public URL.

## Image support
The current version intentionally has no couple image.

When you have an image, create an `images` folder and uncomment the image block in `index.html`.

## QR code
The printed invitation contains a QR code. The website currently leaves that out. If you want, replace the commented QR section with your own QR image later.
