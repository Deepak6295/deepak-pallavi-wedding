# Pallavi & Deepak — Floral Wedding Invitation

GitHub Pages-ready static wedding invitation.

## Files

- `index.html`
- `style.css`
- `script.js`
- `images/location-qr.png`

## Location QR

The QR code opens this Google Maps search:

https://www.google.com/maps/search/?api=1&query=Own%20Residence%2C%20Bongal%20Pukhuri%2C%20Club%20Road%2C%20Jorhat%2C%20Assam

If the exact house pin is different, replace `images/location-qr.png` with a QR generated from your exact Google Maps pin, or update the URL in `index.html`.

## GitHub Pages

Upload all files/folders to the root of your repository, then enable:

**Settings → Pages → Deploy from a branch → main → / (root)**

The site intentionally contains no couple photo yet. You can add one later without changing the rest of the design.
